# PULSE for Windows

音源を端末内で解析するWindowsアプリです。BPM、拍の位置、変速候補を確認できます。音源のアップロードや自動送信は行いません。

## 利用する

[配布ページ](https://github.com/yuuma1on/yuu/releases/latest)の`PULSE-Setup-…-x64.exe`をインストールします。Windows 10/11の64bit版が対象です。Node.jsやffmpegを別途入れる必要はありません。

更新は起動後・定期的に確認し、修正版をバックグラウンドで取得します。準備ができたら「再起動して更新」を選べます。通常の終了時にも、準備済みの更新ファイルを再確認してインストールを開始します。作業中に強制再起動しません。手動確認は「ヘルプ → 更新を確認」から行えます。

このアプリは更新manifestのEd25519署名と、インストーラーのサイズ・SHA512を確認します。認証できない更新、古い版、別リポジトリの更新は適用しません。Windowsの発行元証明書による署名は別の仕組みで、現時点では設定していません。初回の実行時にWindowsの警告が出る場合があります。

## 解析結果について

エンジンはPULSE v1.26.0です。実測の数値と判定保留を保持します。BPMや拍子は推定候補で、音の密度と譜面上の拍単位を常に一意に区別できるわけではありません。複雑な急変速や混合声部には未解決例が残ります。

音源・譜面は利用者が選んだファイルを使います。結果の保存先はダイアログで指定できます。`Ctrl+J`はダウンロードフォルダーを開きます。Web版の解析コードは`source-info.json`の上流コミットから取得し、desktop用の表示をHTMLへ追加しています。

## 開発と配信

```sh
npm ci
npm test
npm run build:win
```

開発用にElectronを起動する場合は、Electron 45のバイナリを`node node_modules/electron/install.js`で取得してから`npm start`を実行します。

配信手順は[RELEASE.md](RELEASE.md)を参照してください。mainへのpushではWindowsのビルド・インストール・起動とデモ解析を確認します。初回配信時点ではGitHub Secrets APIが403を返し、CIの署名鍵は未設定です。そのため、テスト済みの配布ファイルを管理者の端末で署名し、公開する4ファイルだけを手動でReleaseへ追加します。CI配信は、所有者が信頼済みソース・リリースタグ・署名環境の保護を整えてから有効にします。秘密鍵とそのバックアップは非公開で保管し、リポジトリや配布物に含めません。

バグを修正した開発者が新しい版を公開すると、利用者のアプリがその版を検出します。アプリがバグを自動修正する仕組みではありません。
